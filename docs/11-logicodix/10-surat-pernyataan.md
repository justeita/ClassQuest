# Surat Pernyataan Orisinalitas

Sumber: Guidebook LOGICODIX 2026, halaman cetak 20–21.

Surat pernyataan adalah berkas yang membuat tim secara resmi menyatakan karyanya
asli. Karena itu isinya harus benar — bukan formalitas yang ditandatangani tanpa
dibaca.

## Ketentuan berkas

| Item         | Ketentuan                                         |
| ------------ | ------------------------------------------------- |
| Format       | PDF                                               |
| Template     | **Format resmi panitia** — bukan buatan sendiri   |
| Isi          | Diisi dengan data yang benar                      |
| Tanda tangan | Ditandatangani **Ketua Tim**                      |
| Meterai      | Meterai Rp10.000 **atau** e-meterai               |
| Cara kumpul  | Bersama berkas submission lain lewat portal resmi |

## Isi pernyataan

Dengan mengumpulkan surat ini, tim menyatakan:

1. Produk adalah **hasil kerja tim sendiri**.
2. Tim telah **mematuhi seluruh ketentuan orisinalitas** dalam guidebook.

Karena itu, sebelum menandatangani, pastikan pernyataan itu memang benar. Kalau ada
keraguan tentang satu bagian, selesaikan dulu — jangan tanda tangan lalu berharap
tidak diperiksa.

## Yang harus sudah beres sebelum tanda tangan

| Pernyataan                                    | Bukti yang harus ada                                      |
| --------------------------------------------- | --------------------------------------------------------- |
| Kode ditulis tim sendiri selama Hacking Week  | Riwayat commit yang menunjukkan penambahan bertahap       |
| Tidak ada kode dari proyek sebelum lomba      | Tidak ada snapshot proyek lama di repo                    |
| Tidak ada bagian utama yang dibuat pihak luar | Setiap anggota bisa menjelaskan bagian yang dikerjakannya |
| Komponen pihak ketiga diatribusikan           | Bagian Atribusi di README                                 |
| Karya belum pernah dilombakan                 | Konfirmasi seluruh anggota                                |
| Penggunaan AI didokumentasikan                | Bagian Penggunaan AI di README                            |

## Data yang perlu disiapkan

Siapkan sekali, jangan dicari saat mepet:

- Nama tim.
- Nama lengkap Ketua Tim sesuai identitas.
- Nama dan asal instansi seluruh anggota.
- Judul karya dan kategori (Web).
- Nama subtema.
- Tautan repositori.
- Tautan video demo.
- Tempat dan tanggal penandatanganan.

## Prosedur

1. **Unduh template resmi** dari kanal panitia. Jangan membuat format sendiri.
2. Isi semua field. Jangan ada yang dikosongkan atau ditulis "menyusul".
3. Cetak, tanda tangani Ketua Tim, bubuhi meterai.
4. Pindai menjadi PDF. Pastikan hasil pindai terbaca dan tidak terpotong.
5. Periksa ukuran file — PDF hasil pindai berwarna resolusi tinggi bisa sangat
   besar; portal submission bisa menolaknya.
6. Simpan salinan di tempat yang bisa diakses seluruh anggota.
7. Kumpulkan lewat portal bersama berkas lain.

## Kesalahan yang membuat surat tidak sah

| Kesalahan                                    | Akibat                         |
| -------------------------------------------- | ------------------------------ |
| Memakai format buatan sendiri                | Tidak sesuai ketentuan panitia |
| Tanpa meterai                                | Tidak memenuhi syarat          |
| Ditandatangani bukan Ketua Tim               | Tidak sah                      |
| Dikirim dalam format selain PDF              | Tidak sesuai ketentuan         |
| Data anggota berbeda dengan data pendaftaran | Bisa dipertanyakan             |
| Nama tim berbeda dengan yang di README       | Tidak konsisten                |
| Dikirim lewat WhatsApp/email, bukan portal   | Tidak dianggap submission sah  |

## Konsistensi data

Nama tim, daftar anggota, nama aplikasi, dan kategori harus **sama persis** di:

1. Form pendaftaran.
2. Surat pernyataan orisinalitas.
3. `README.md`.
4. Video demo (bila disebut).
5. Form submission.

Satu perbedaan kecil bisa memicu permintaan klarifikasi. Buat satu tabel data
identitas di [`11-submission-checklist.md`](./11-submission-checklist.md) dan
salin dari situ, jangan mengetik ulang dari ingatan.

## Checklist

- [ ] Template resmi panitia dipakai.
- [ ] Semua field terisi.
- [ ] Ditandatangani Ketua Tim.
- [ ] Meterai Rp10.000 atau e-meterai terpasang.
- [ ] Berformat PDF dan terbaca.
- [ ] Data identitas sama dengan README dan form pendaftaran.
- [ ] Salinan tersimpan dan bisa diakses seluruh anggota.
- [ ] Dikumpulkan lewat portal, bukan kanal lain.
